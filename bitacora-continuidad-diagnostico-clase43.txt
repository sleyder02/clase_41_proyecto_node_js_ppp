1. ¿Qué es continuidad operativa?
Respuesta:La continuidad operativa es la capacidad de una plataforma para mantenerse funcionando 
y accesible sin interrupciones, asegurando que el servicio no se detenga ante fallos técnicos, errores de código o picos de tráfico.

2. ¿Qué es PM2?
Respuesta:Vigila que la aplicasion no se duerma 
Es el programa que se encarga de vigilar, mantener vivo y optimizar tu servidor las 24 horas del día.

3. ¿Qué comando usé para iniciar la aplicación con PM2?
Respuesta: npx pm2 start server.js --name app-semana9

4. ¿Qué comando usé para listar procesos?
Respuesta:npx pm2 list

5. ¿Qué comando usé para detener la aplicación?
Respuesta:npx pm2 stop app-semana9

6. ¿Qué comando usé para reiniciar la aplicación?
Respuesta:npx pm2 restart app-semana9

7. ¿Qué comando usé para revisar logs?
Respuesta:npx pm2 logs app-semana9 --lines 20
