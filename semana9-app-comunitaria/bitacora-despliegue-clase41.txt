1. ¿Qué significa desplegar o levantar una aplicación?
Respuesta:Levantar significa encender el proceso de la aplicación en memoria (ej. npm start) para que empiece a escuchar peticiones, mientras que desplegar es trasladar ese código a un servidor en producción para que el público pueda acceder a él a través de internet.

2. ¿Qué diferencia hay entre código escrito y aplicación ejecutándose?
Respuesta:El código escrito es el plano estático-sin vida (texto pasivo en archivos de texto o Git), mientras que la aplicación ejecutándose es ese plano cobrando vida en la memoria RAM como un proceso activo que consume CPU y responde peticiones.

3. ¿Qué variable de entorno se usó para definir el puerto?
Respuesta:Se utilizó la variable de entorno PORT (invocada en el código como process.env.PORT), la cual permite al sistema operativo asignar dinámicamente el puerto del servidor.
